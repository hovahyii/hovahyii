Part 1 · AGConnect 控制台准备
在华为开发者后台完成项目配置
#步骤操作位置
1开通 HMS Kit
选择你需要的 Kit（Push / Analytics / Map 等）		My apps → APIs
2下载配置文件
获取 agconnect-services.json		Project settings → App information
3配置签名指纹
填入 SHA-256（debug 和 release 都要）		Project settings → App information
4开发者实名认证
确保华为开发者账号已完成实名认证		华为开发者账号设置

Part 2 · Android Studio 工程配置
Gradle 依赖、插件、混淆规则
A
放置配置文件
将 agconnect-services.json 放到 app/ 根目录（和 build.gradle 同级），不是 project 根目录。
B
Project 级 build.gradle（或 settings.gradle）
添加 HMS Maven 仓库和 agcp classpath
build.gradle (Project)
repositories {
    google()
    mavenCentral()
    maven { url 'https://developer.huawei.com/repo/' }  // HMS Maven 仓库
}

dependencies {
    // buildscript 里
    classpath 'com.huawei.agconnect:agcp:1.9.1.301'  // AGConnect 插件
}
⚠️
新版 Gradle 用 settings.gradle 的 dependencyResolutionManagement 管理 repositories 时，把 maven URL 放到那里。
C
App 级 build.gradle
应用 agcp 插件 + 按需引入 HMS Kit 依赖
build.gradle (app)
plugins {
    id 'com.android.application'
    id 'com.huawei.agconnect.agcp'  // AGConnect 插件
}

android {
    // ...
    signingConfigs {
        release {
            storeFile file('xxx.jks')
            storePassword 'xxx'
            keyAlias 'xxx'
            keyPassword 'xxx'
        }
    }
}

dependencies {
    // HMS Core 基础包
    implementation 'com.huawei.hms:base:6.11.0.301'

    // Push Kit
    implementation 'com.huawei.hms:push:6.11.0.300'

    // Analytics Kit
    implementation 'com.huawei.hms:hianalytics:6.11.0.301'

    // Map Kit
    implementation 'com.huawei.hms:maps:6.11.0.301'
}
D
混淆规则 proguard-rules.pro
proguard-rules.pro
# HMS Core
-keep class com.huawei.hianalytics.**{*;}
-keep class com.huawei.hms.**{*;}
-keep class com.huawei.agconnect.**{*;}
-dontwarn com.huawei.hms.**

Part 4 · 签名指纹获取
用 keytool 获取 SHA-256 填入 AGConnect 控制台
Terminal — keytool 命令
# Debug 签名
keytool -list -v -keystore "%USERPROFILE%\.android\debug.keystore" \
  -alias androiddebugkey -storepass android -keypass android

# Release 签名
keytool -list -v -keystore your_release.jks
💡
把输出里的 SHA-256 值填到 AGConnect 控制台的 Project settings → App information。
📌
Part 5 · 关键注意事项
事项说明
海外设备HMS Core 需要设备上有 HMS 框架；中国大陆华为设备默认有，海外设备需安装 HMS Core APK
和 GMS 共存用 HuaweiApiAvailability 判断是否支持 HMS，不支持时 fallback 到 GMS
agconnect-services.json包含 app_id、api_key 等配置，必须放在 app/ 目录，不要提交到公开仓库
多 flavor每个 flavor 可能需要单独的 json，放在 src/{flavor}/ 下
网络构建时需要能访问 developer.huawei.com/repo Maven 仓库

Part 7 · Android Studio 版本兼容性
没有华为官方强制要求，约束来自 AGP 和 agcp 插件
组件要求
Android StudioArctic Fox (2020.3.1)+   推荐 Hedgehog (2023.1.1)+
AGP7.0+（对应 agcp 1.9.x）
Gradle7.0+（AGP 7.x）；AGP 8.x 需 Gradle 8.x
JDKJDK 11（AGP 7.x 最低）；AGP 8.x 需 JDK 17
compileSdk31+（推荐 34 或最新）
minSdk各 Kit 不同，一般 19+，部分 Kit 要求 21+

核心原因：agcp（AGConnect Gradle Plugin）1.9.x 依赖 AGP 7.x+，AGP 7.0 对应 Android Studio Arctic Fox，这就是实际最低线。
🔌 HMS Toolkit 插件（可选但推荐）

华为提供的 Android Studio 插件，可自动配置 HMS Maven 仓库、下载 agconnect-services.json、一键添加 Kit 依赖、检查配置问题。

安装路径
Settings → Plugins → 搜索 "HMS Toolkit" → Install
⚠️ 不要搞混 IDE
IDE用途
Android StudioHMS Core（Android 平台）开发 ✅
DevEco StudioHarmonyOS / HarmonyOS NEXT 开发，不用于 HMS Core Android 接入
